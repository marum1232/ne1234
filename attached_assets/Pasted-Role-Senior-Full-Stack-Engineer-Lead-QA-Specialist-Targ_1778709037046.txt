Role: Senior Full-Stack Engineer & Lead QA Specialist
Target Module: Rider App (Complete End-to-End)
Objective: Aapka maqsad "Rider App" ke module ko zero-bug aur production-ready banana hai. Is mein Frontend (Mobile/Web), Backend (API/Controllers), aur Database (Queries/Schemas) ka poora flow shamil hai.
Execution Instructions (Step-by-Step):
Dependency Mapping: Sab se pehle Rider App se judi hui tamam files (Controllers, Models, Routes, Screens, Hooks) ki list banayein. Check karein ke Backend aur Frontend ke darmiyan koi communication gap to nahi?
State & Lifecycle Audit:
Frontend: Verify karein ke Rider ki online/offline state, location updates, aur order acceptance logic mein koi "Memory Leak" ya "Infinite Loop" to nahi hai.
Backend: Check karein ke jab Rider status change karta hai, to database mein transaction lock sahi lag raha hai ya nahi (Concurrency issues).
Real-Time Flow (Socket/SSE): Rider app ka main kaam real-time tracking hai. Verify karein ke agar Rider ka internet disconnect ho jaye, to reconnect hone par "Live Tracking" aur "Order Sync" khud ba khud recover hota hai ya nahi.
Security & Auth Audit: Rider app ke har API endpoint par AuthMiddleware aur Role-Based Access check karein. Koi bhi rider kisi dusre rider ka data ya admin ka data access na kar sakay.
Data Integrity: Input validation (Zod/Joi) lagayein. Check karein ke Database mein koi "Null" value na jaye jahan "Required" honi chahiye.
Production Readiness:
Tamam console.log khatam karein aur logger.ts use karein.
Error boundaries lagayein taake app crash hone par blank screen na dikhaye balkay "Retry" ka option de.
Loading states aur Skeleton screens add karein.
Deliverables:
File Inventory: Is module ki tamam files ki list.
Gap Analysis Report: Wo jaghain jahan logic adhoora hai (e.g., Missing 401 handling, Silent catches).
The "Fix" Plan: In gaps ko khatam karne ka step-by-step code solution.
Verification Check: Confirmation ke End-to-End flow (Rider Login -> Ride Request -> Pickup -> Drop-off -> Payment) 100% kaam kar raha hai.
