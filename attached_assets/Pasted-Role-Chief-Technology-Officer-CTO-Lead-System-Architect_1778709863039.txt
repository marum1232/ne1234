Role: Chief Technology Officer (CTO) & Lead System Architect
Project: ajkmart (Full-Stack Multi-Module Application)
Objective: Aapka mission ajkmart ki poori app ko "Industry Standard" par lana hai. Is app mein multi-modules (Customer, Rider, Vendor, Admin) hain. Aapne in sab ke darmiyan Data Flow, Security, aur Real-time Sync ko audit aur fix karna hai taake End-to-End flow 100% stable ho.
Execution Scope (The Full Stack):
Cross-Module Synchronization (The Bridge):
Check karein ke jab Customer order place karta hai, to kya wo Vendor ko foran receive hota hai aur Rider ko "Nearby" notification jata hai?
Database transactions ko audit karein taake "Double Payment" ya "Order Lost" jaise masle na hon.
Frontend & UI/UX Consistency (All Apps):
Customer, Rider, aur Vendor apps mein TypeScript errors ko 0 karein.
Shared Components: Check karein ke utils, hooks, aur constants saaray modules mein sahi tarah share ho rahe hain ya nahi.
Har screen par Loading, Empty, aur Error states lazmi honi chahiye.
Backend & API Architecture:
Unified Auth: Check karein ke AuthContext aur token refresh logic har app mein consistent hai.
Error Propagation: Backend ka error frontend par "User-friendly message" ban kar dikhna chahiye, na ke "Internal Server Error".
Real-Time & Infrastructure:
Socket.io / SSE: Live tracking (Customer-Rider) aur Chat logic ko stress-test karein. Agar connection drop ho, to auto-reconnect logic check karein.
Environment Variables: Verify karein ke Production aur Development ke URLs aur Keys (Maps, Firebase, Payments) alag aur secure hain.
Database & Security:
Input Sanitization: Har API par validation (Zod/Joi) lagayein taake database mehfooz rahe.
Indexing: Database queries ko check karein ke wo slow to nahi hain (Scalability check).
Deliverables Required:
Architecture Map: Tamam modules aur unke connections ki list.
Critical Fixes List: Wo bugs jo poori app ko block kar rahe hain.
Code Completion: Incomplete logic (// TODOs) ko robust code se replace karein.
Final E2E Validation: Aik mukammal report ke "Order Placement -> Preparation -> Rider Pickup -> Delivery -> Payment Completion" ka flow perfect kaam kar raha hai.
