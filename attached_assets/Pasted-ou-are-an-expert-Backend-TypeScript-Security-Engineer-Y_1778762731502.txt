3. DATA PRIVACY: Exclude sensitive information (such as raw DB passwords, user PII, or full system stack traces) from the JSON responses sent back to the client. Return clean, user-friendly error messages with appropriate HTTP Status Codes.
4. RUNTIME SAFETY: Ensure that adding try-catch blocks or changing promise chains does not introduce unintended race conditions or break the asynchronous execution flow.
